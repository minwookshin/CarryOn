# CarryOn 2.7 · 아이콘 크기

- 기본 아이콘을 32dp에서 48dp로 확대했습니다. 하단 탭, 설정, 지도 조작과 버튼에 같은 크기를 적용하고 기존 76dp 터치 영역을 유지합니다. 수량 카드의 큰 상자 아이콘은 64dp를 유지합니다.
- 기준은 [Pleos Iconography의 기본 48 × 48dp 그리드](https://document.pleos.ai/en/docs/connect/guide/docs-design/foundations/contents-creation/iconography)입니다. Carbon 색상과 현재 아이콘 스타일을 유지합니다.
- 지도 오른쪽 위 버튼의 방향 화살표를 제거하고 `2D/전체` 글자 버튼으로 표시합니다. 버튼 높이를 다른 지도 조작과 같은 76dp로 맞췄습니다.
- 현재 남은 업무 카드의 같은 방향 화살표도 제거했습니다. 안내 중인 장소의 파란 테두리·경로 점·접근성 설명은 유지합니다.
