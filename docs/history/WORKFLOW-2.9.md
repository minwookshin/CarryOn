# CarryOn 2.9 · 경로 점 정렬

- 현재 남은 업무의 파란색/회색 경로 점을 각 카드의 실제 세로 중앙에 배치합니다. 카드 사이 16dp 간격은 중심 계산에서 제외합니다.
- 카드 높이가 달라져도 점과 연결선이 카드에 맞춰 배치됩니다.
- 동·라인 목록은 읽기 전용이며 상세 화면이나 누름 동작을 추가하지 않았습니다.
