# CarryOn 2.6 · 현재 업무 표시 정리

- 택배·화물 현재 업무의 회차·작업 종류 문구를 제거했습니다. 장소명부터 표시하고, 수량·도크·인수 결과는 유지합니다. 종료 후 미처리 목록도 장소명으로 표시합니다.
- 현재 작업 처리 완료 상태와 지도에서 `다음 배정 대기` 문구를 제거했습니다. 현재 방문지 완료가 하루 업무 종료를 뜻하지 않으며, 회사의 CURRENT 이벤트가 다음 목적지를 변경하는 규칙은 유지합니다.
- 화물칸의 현재 온도, 마지막 문 상태, 미확인·미수신 표시는 현재 업무에 유지합니다. 온도 기록 펼치기는 설정에만 있습니다.
- 본문과 설정의 항목 간격을 24dp로 맞췄습니다. 수량·상태·온도 카드의 안쪽 여백은 20dp입니다. 설명이 없는 완료 카드는 빈 줄을 만들지 않습니다.
- Carbon 색상·글꼴, 고정 지도, 두 탭과 스와이프, 업무 데이터·인증·센서 연결은 유지합니다.
