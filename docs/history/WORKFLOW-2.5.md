# CarryOn 2.5 · 장소별 남은 업무

- 설정 아이콘은 이름·업무 유형 오른쪽에 고정합니다. 하단은 현재 업무 / 현재 남은 업무 두 탭이며 스와이프로 전환합니다.
- 설정을 닫으면 이전 탭과 스크롤 위치로 돌아갑니다. 업무 유형 저장은 설정으로 돌아옵니다. 지도와 현재 목적지는 화면 전환에 영향을 받지 않습니다.
- 현재 업무에서 진입 설명, 동·라인·출입구 행, 개별 물품 상세 페이지를 제거했습니다. 수량·회수·정차·화물 조건·인수 상태는 유지합니다. 세부 데이터는 삭제하지 않고 단말 결과를 그대로 받습니다.
- 현재 남은 업무는 배정 순서를 잇는 장소별 카드입니다. 장소명과 업무 수량을 표시하고, 안내 중인 장소는 굵은 파란 테두리와 방향 아이콘으로 구별합니다. ‘현재 방문지 / 바로 다음 / 그 다음 / 다음 예정’ 문구와 별도 목록 펼치기를 제거했습니다.
- 이전 방문지의 미처리, 반품 회수, 회사 확인 대기 결과는 계속 남습니다. 처리와 전송이 확인된 장소만 목록에서 빠집니다. 카드는 배차 순서나 목적지를 변경하는 버튼이 아닙니다.
- 확인된 운행·정차 구간과 최근 기록은 설정에 있습니다. 정상 차량 값과 미수신 안내 표는 남은 업무에 표시하지 않습니다.
- 차량의 최신 연료·배터리·주행 가능 거리 값이 부족할 때만 닫을 수 있는 Carbon 토스트를 표시합니다. 키보드 포커스를 강제로 옮기지 않으며 접근성 권장 읽기 시간을 적용합니다. 같은 상태를 매번 재알림하지 않습니다.

## 차량 알림의 현재 정책

앱에서 정한 안내 기준이며 제조사 경고 신호를 대신하지 않습니다. 90초 이내의 유효한 수신 값만 사용합니다. 연료·배터리 15% 이하 / 주행 가능 거리 40km 이하에서 안내하고, 5% / 15km 이하로 악화되면 한 번 더 알립니다. 재충전·주유 후 20% / 50km를 넘는 값이 확인되어야 같은 안내를 다시 시작합니다. 값 미수신·오래된 값·잘못된 값으로 경고하지 않습니다. 현재 에뮬레이터에서 이 에너지 API 값이 미수신이면 알림이 없는 것이 정상입니다.

## 검증

단위 검사 187개 통과. 남은 업무 필터는 이전 미처리·반품·전송 대기를 보존하고, 알림은 최신 값·반복 억제·회복·악화·복수 값 우선순위를 확인합니다. 에뮬레이터 검증의 실제 결과는 이 버전 작업의 확인 기록과 함께 남깁니다. 합성 저연료 값의 화면 검증은 별도 QA 앱의 계측 테스트에서만 실행하며 일반 APK에는 테스트 차량 값을 주입하는 기능이 없습니다.

지도와 목적지 전달 방식은 2.4와 같습니다. 공식 기본 내비의 지도/GPS 제한을 해결한 버전은 아닙니다. 상세한 단말 업무 처리는 차량 UI에서 다시 입력하지 않습니다.

에뮬레이터에서 설정 열기·닫기와 업무 유형 복귀, 양방향 스와이프, 넓은/한 칸 화면과 큰 글자, Tab·Shift+Tab 순회, 왼쪽 지도 영역 유지, 배송 부분 처리·전송 대기·반품 회수·다음 배정·예시 도착, 화물 03 도크·인수 대기/확인·센터 복귀를 단독 확인했습니다. 저연료 12% 토스트는 QA 앱에서 합성 값으로 표시·닫기를 확인했습니다. 일반 앱 업그레이드 후 기존 업무 75건과 현재 배정이 보존됐습니다. Lint는 오류 0개·경고 30개입니다. TalkBack의 실제 음성으로 전체 과정을 순회하거나 실차 저연료 이벤트를 시험한 것은 아닙니다.

차량 연결 직후와 기존 20초 갱신 주기에 에너지 조회를 연결했습니다. 주행 가능 거리 읽기에 필요한 `android.car.permission.CAR_ENERGY`도 선언·요청하며, 권한이 없으면 조회를 생략합니다. [AAOS RANGE_REMAINING 공식 규격](https://developer.android.com/reference/android/car/VehiclePropertyIds#RANGE_REMAINING)을 기준으로 미터 값을 km로 변환합니다. 지원되지 않는 값은 알림을 만들지 않습니다.
