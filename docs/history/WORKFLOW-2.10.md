# CarryOn 2.10 · 도착 후 주차 안내

- 업무 변경 문구를 “다음 업무로 업데이트되었습니다”로 변경했습니다.
- 주차 브레이크 안내는 현재 방문지의 경로가 도착 상태이고, 차량이 정차/P 상태일 때만 표시합니다. 연결 전·이동 중·이전 방문지의 도착 상태에서는 표시하지 않습니다.
- 브레이크 해제는 “주차 브레이크를 체결해 주세요”, 값이 없으면 확인 불가로 구분합니다. 체결되면 안내를 숨깁니다.
- 택배와 화물에 같은 도착 판정과 차량 상태 조건을 사용합니다. 다음 방문지를 받으면 이전 도착 안내를 유지하지 않습니다.
- 영상은 Pleos 에뮬레이터의 상단 상태 표시줄, 왼쪽 차량 상태, 하단 메뉴를 모두 포함한 전체 화면을 다시 녹화했습니다. Carbon 앱과 기존 예시 지도/단말 흐름을 유지했습니다.

## 확인

- `testDebugUnitTest assembleDebug lintDebug` 성공: 단위 테스트 189개 통과, Lint 오류 0개/기존 경고 30개.
- 별도 QA 설치에서 QR 승인 → 이동 → 남은 업무 → 자동 도착 → 배송 12 → 4 → 0, 회수 2 → 0 → 다음 방문지 흐름을 녹화했습니다.
- 이동/목록 화면에서 주차 안내 없음, 도착/현장 작업에서 표시, 다음 방문지 이동에서 사라짐을 실제 UI 계층으로 확인했습니다.
