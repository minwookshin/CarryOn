# 직접 확인할 흐름

## 배송·회수

1. 김민준으로 QR 연결 체험을 진행합니다.
2. 한빛아파트의 배송 12개·회수 2건, 적재 위치를 보고 **안내 시작**을 누릅니다.
3. 앱 지도에서 약 18초 이동 후 자동 도착합니다. 왼쪽 지도는 유지되고 오른쪽에 정차·하차 정보가 표시됩니다.
4. **단말에서 작업하기**를 열어 배송 11/12개·회수 1/2건을 전송합니다.
5. 결과 수신 후 **재탑승 · 결과 확인**을 누릅니다. 미배송 1개·미회수 1건이 표시됩니다.
6. **단말에서 미처리 확인**에서 배송 12/12개·회수 2/2건으로 보완하고 다시 전송합니다. 미처리 사유로 인계하는 경로도 있습니다.
7. 결과를 확인하고 **다음 방문지 안내**를 누릅니다. 결과 수신만으로 출발하지 않습니다.
8. 한빛상가 배송 5개, 다온오피스 배송 8개·회수 1건도 결과 수신 → 재탑승 → 다음 안내로 진행합니다.
9. 센터 복귀·자동 도착 후 회수 3건·미배송 0개를 확인하고 **인계 완료 · 운행 종료**로 마칩니다.

## 화물

기사 교대로 박지호를 연결합니다. 상차지 이동 → 도크 배정 → 상차 → 출발 준비 → 하차지 이동 → 도크 배정 → 하차 → 인수 확인 → 용기 회수 → 센터 인계 순서입니다. 도크는 예시 데이터를 자동으로 받고, 수량·인수·출발 준비는 직접 확인합니다.

## 검증과 한계

- 1.25 단위 검사 131개 통과. 배송·회수 전체 흐름은 2026-11-02에 직접 확인했습니다. 화물 전체 흐름은 1.24에서 확인했고, 1.25에서 다시 반복한 것은 아닙니다.
- 왼쪽 지도는 넓은 앱 창에서 방문지·단말·결과 화면을 열어도 유지됩니다. 130% 글자 및 실제 한 칸·두 칸 레이아웃을 확인했습니다.
- 키보드 포커스와 설명을 제공하지만 최근 버전의 TalkBack 음성 전체 여정을 다시 검증한 것은 아닙니다.
- 실제 서버 인증, 휴대폰 앱, TMS, 실차 GPS 주행은 이 테스트에 포함되지 않습니다.
- 영상은 실제 앱 화면 778프레임과 클릭 23건을 바탕으로 약 2분 56초로 편집했습니다. 조작 사이 확인 대기를 줄였으며 포인터 이동·클릭 강조는 클릭 기록을 따라 후처리했습니다. 30fps 출력이 원본 30fps 화면 녹화를 뜻하지는 않습니다.
