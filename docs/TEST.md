## 서명된 APK에서 확인한 흐름

1. 새로운 시연 패키지 설치 → 업무 유형 선택 → QR과 코드 발급.
2. 같은 Mac의 시험 단말에서 코드 승인 → 기사와 한빛아파트 배차 수신.
3. 앱 지도에서 예시 이동 → 현재 남은 업무 탭 확인 → 자동 도착.
4. 이동 중 주차 브레이크 안내 없음 → 도착 후 정차/P 상태에서 체결 안내 표시.
5. 단말의 부분 배송 결과로 12개 → 4개 반영.
6. 배송 결과를 모두 반영한 후 회수 2건이 남는 것을 확인.
7. 회수 결과 반영 → 현재 작업 처리 완료. 단말의 다음 업무 지시 전에는 방문지가 유지됨.
8. 다음 방문지 지시 수신 → 한빛상가 배송 56개·이동 안내·업무 변경 메시지 표시. 이전 방문지의 주차 브레이크 안내는 사라짐.

현재 남은 업무 탭에서 Tab·Shift+Tab 입력 후 화면이 유지되는 것을 확인했습니다. 이번 배포 확인에서 TalkBack 음성 전체 여정을 새로 검증한 것은 아닙니다. 기존 작업 앱과 시연 패키지는 분리되어 있으며 원래 작업 기록을 초기화하지 않았습니다.
