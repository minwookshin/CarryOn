# 현재 2.2 시험

[택배·화물 전체 시험 순서](../integration/README.md) · [검증 결과와 한계](../WORKFLOW-2.2.md) · [공유 MD 대조](MD-ALIGNMENT.md)

2.2 단위 검사 179개, APK 빌드와 Lint 오류 0개(경고 30개)를 확인했습니다. 좁은 화면·큰 글자·넓은 화면에서 다음 두 곳·… 목록·복귀, 택배 상가 표시, 화물 도크, 현재 업무·현황·설정의 지도 유지, 기본 내비 재진입을 직접 확인했습니다. 새 … 버튼은 Tab·Shift+Tab·Enter·Back으로 확인했습니다. 검증은 서브에이전트 없이 단독으로 수행했습니다.

2.1에서 검증한 설정 저장 후 업무 보존, 부분 배송·회수·미처리, 화물 인수·운전 종료, 냉동 이탈·미수신의 회귀 검사는 2.2 단위 검사에 포함됩니다. 이번 공유 준비에서 동일한 회사 시험 서버의 HTTP 검사 13개를 재실행해 모두 통과했습니다. APK 서명과 테스트한 파일의 SHA-256 일치도 확인했습니다. TalkBack 음성·표준 제스처 전체 여정과 실제 기본 내비의 GPS 주행·자동 도착은 검증 미완료입니다.

직접 확인할 항목:

1. 택배 예시에서 현재 한빛아파트 배송·회수 수량과 다음 한빛상가·새봄 거래처를 확인합니다. …를 열고 돌아와도 현재 업무는 그대로여야 합니다.
2. 큰 글자와 한 칸/넓은 화면에서 지도와 다음 두 곳이 겹치지 않는지 봅니다. 운송 현황·설정에 들어가도 지도 위치를 유지해야 합니다.
3. 시험 단말에서 일부 배송·회수 결과를 보내고 남은 수량을 확인합니다. 현재 방문지 변경을 보낼 때만 다음 목적지로 이어져야 합니다.
4. 화물 연결 후 도크 호출·상하차·별도 인수·용기 회수·센터 인계를 진행합니다. 인수 미완료와 전송 대기를 물량 0으로 숨기지 않아야 합니다.
5. Tab·Shift+Tab으로 …에 접근하고 Enter로 목록을 연 뒤 Back으로 돌아옵니다. 작업 결과를 스와이프로 입력하는 동작은 없습니다.

이전 1.25 영상은 재탑승·완료 버튼을 사용하던 흐름입니다. 현재 앱은 단말의 확인된 업무 기록을 수신합니다.
