# CarryOn 2.4 시험

[택배·화물 전체 시험 순서](../integration/README.md) · [2.4 변경과 검증](../WORKFLOW-2.4.md) · [공유 MD 대조](MD-ALIGNMENT.md)

단위 검사 179개, APK 빌드, Lint 오류 0개(경고 31개)를 확인했습니다. 이번 화면 검증은 별도 QA 패키지와 단말 서버에서 단독으로 수행했으며 기존 앱의 배차·물품 75건을 보존해 업데이트했습니다.

직접 확인할 항목:

1. 넓은 창에서 왼쪽 지도와 오른쪽 업무를 봅니다. 기사 이름·알림은 오른쪽에만 있고, 현재 업무 하단의 다음 두 곳·합계 영역은 없어야 합니다.
2. 지도에서 전체 경로, 확대·축소, 현재 위치 복귀를 조작합니다. 현재 방문지와 처리 결과가 바뀌거나 이동이 재시작되면 안 됩니다.
3. 하단 탭과 양방향 스와이프로 현재 업무·현황·설정을 오갑니다. 지도는 제자리를 유지합니다. 지도 위 스와이프로 업무 탭이 바뀌면 안 됩니다.
4. 한 칸과 큰 글자에서도 내용을 세로로 스크롤하고 출입구 상세에서 돌아옵니다. 지도·아이콘·본문이 겹치지 않아야 합니다.
5. 단말에서 배송·회수 결과를 보내면 수량과 완료 상태가 갱신됩니다. 현재 방문지 변경을 보내면 다음 예시 경로로 이동하고 도착합니다. 다른 탭에서도 이동이 이어져야 합니다.
6. 화물의 도크 호출, 상하차·별도 인수, 냉동 정보는 단말의 확인된 기록을 사용합니다. 이전 버전의 완료·재탑승 버튼을 다시 만들지 않습니다.
7. Tab·Shift+Tab으로 지도 버튼 → 출입구 → 하단 탭을 순방향/역방향으로 순회합니다. 숨은 페이지가 열리면 안 됩니다. 모든 새 지도 버튼과 탭에 설명과 76dp 이상의 조작 영역이 있습니다.

TalkBack에서는 새 지도 버튼과 하단 탭의 설명·접근성 포커스 동작을 확인하고 원래 시스템 설정으로 복원했습니다. 자연스러운 음성·표준 제스처 전체 여정과 공식 기본 내비의 GPS 주행·자동 도착은 검증 미완료입니다. 앱 지도는 기존 OpenStreetMap 지형과 예시 이동을 사용합니다.

[2.3 이전 검증 기록](../WORKFLOW-2.3.md)은 해당 버전의 화면과 범위를 설명합니다.
