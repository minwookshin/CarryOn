# Mac 단말과 에뮬레이터 시험

이 도구는 회사 단말이 보낼 데이터를 별도 프로세스에서 공급합니다. 앱 안에서 업무 완료를 흉내 내는 버튼을 제거하고 실제 HTTP 요청과 수신·저장·화면 갱신을 시험하기 위한 도구입니다. 가상 기사·배차이며 실제 차량이나 회사 기록을 변경하지 않습니다.

## 연결

```sh
export ANDROID_HOME=/path/to/android-sdk
./scripts/run-local-integration.sh
```

Pleos 에뮬레이터가 실행 중이어야 합니다. 서버는 **127.0.0.1:8797**에만 바인딩하고 `adb reverse`가 에뮬레이터의 동일 포트를 Mac으로 연결합니다. 8787 등 다른 개발 서비스 포트는 사용하지 않습니다. 이미 서버가 실행 중이면 같은 서버의 `/control`을 이용하세요.

1. [단말 시험 화면](http://127.0.0.1:8797/control)을 브라우저로 엽니다.
2. 최초 업무·차량 설정 후 차량 앱 상단 설정 → 단말 연결. 이후에는 저장된 업무와 연결을 복원합니다.
3. 차량의 8자리 코드와 Mac에 입력된 코드가 일치하는지 확인하고 시험 기사를 선택해 승인합니다. 코드가 자동으로 입력되어도 승인을 누르기 전까지 연결되지 않습니다.
4. 차량은 기사와 배차를 받고 계속 동기화합니다. 연결 중지·재연결 시 이전 작업 기록은 지우지 않습니다.
5. 움직이는 화면을 보려면 차량 설정에서 **앱 지도 · 이동 시험**을 선택합니다. 예시 이동은 P·정차 상태에서만 진행합니다.

실제 휴대폰 SSO나 외부 공개 주소를 제공하지 않으므로 휴대폰에서 이 루프백 QR을 열 수는 없습니다. 본 도구를 `0.0.0.0`이나 인터넷으로 공개하지 않습니다. 운영용 연결 설계는 [CONTRACT.md](CONTRACT.md)를 참고하세요.

## 택배

1. 김민준 · 택배 승인 → 한빛아파트 배송 12개, 회수 2건 확인.
2. **8개 배송 결과 보내기** → 차량에 남은 4개 및 출입구별 잔량 확인. 차량 복귀/완료 버튼 없음.
3. 현재 작업을 **새봄 거래처**로 전환하고 집하 수량 처리.
4. **동부 터미널**로 전환하고 인계 처리. 하루 종료로 바뀌지 않음.
5. **1회차 한빛아파트**로 복귀. 이전 물품 번호와 잔량 유지.
6. 물품별 결과에서 이전 방문지 작업을 보내도 현재 방문지는 바뀌지 않음.
7. **단말 처리 · 전송 대기**와 **전송 대기 결과 서버 반영**을 구분해 확인.
8. 남은 배송·회수, 한빛상가 배송 처리 후 **2회차 한빛아파트** 전환. 같은 주소의 새 물품 2개 확인.
9. **동부 캠프** 인계와 **업무 시스템 종료 기록**을 각각 전송.

현재 작업 전환은 시험 회사 시스템의 확인된 배정 이벤트입니다. 물량 0·위치상 도착·단순 차량 복귀만으로 자동 전환하지 않습니다. 새 방문지 이벤트를 수신하면 앱 지도에서는 다시 이동·도착까지 연결됩니다.

## 화물

1. 차량 설정에서 연결 중지 후 새 코드를 요청하고 **박지호 · 장거리 화물**로 승인합니다. 이전 택배 기록은 별도 보존됩니다.
2. 중앙저온센터 도착과 **접수 기록**, **03번 도크 호출**, **상차 수량 처리**를 각각 확인합니다.
3. **미래물류센터** 전환 → 도착 → 접수/호출 → 하역 수량 처리.
4. 하역 0이어도 **인수 미완료**가 유지되는지 확인하고 별도로 **서명·인수 완료 전송**.
5. 미완료 운송이 있는 상태에서 **오늘 운전 종료 기록** → 앱 재실행 → 수량·미완료 인수 유지. 운전 재개 기록으로 이어갑니다.
6. 중앙용기센터 회수 → 중앙운송센터 인계 → 별도 업무 종료 기록.

## 냉장·냉동, 오류와 접근성

- 시험 **단말**의 냉동 옵션은 택배/화물 모두 사용 가능. 단말 옵션 변경 시 새 데이터 흐름을 발급하지만 물품 기록은 유지합니다. 차량 앱의 기본 옵션 저장은 현재 회사 배정이나 센서 조건을 바꾸지 않습니다.
- **−19°C** → **−15°C 이탈** → **문 열림 + 이탈** → **설정 온도 불일치**. 문 열림이 이탈을 정상으로 만들지 않습니다.
- **수신 멈추기** 후 15초가 지나면 현재 온도 확인 불가. 마지막 값·시각·문 상태는 과거 기록으로 표시합니다. 운송 현황에서 최근 기록을 확인합니다.
- 서버를 종료해도 앱의 작업을 유지하고 연결 오류를 표시합니다. 다시 서버를 실행하면 같은 스트림의 커서를 이어 받습니다.
- Tab / Shift+Tab / Enter로 현재 업무, 운송 현황, 설정, 출입구 상세, 돌아가기를 확인합니다. 큰 글자와 정차 중 상세 화면을 선택할 수 있습니다.
- 데이터 갱신은 포커스를 자동으로 다른 업무로 옮기지 않아야 합니다. 현재 방문지 변경으로 상세가 사라질 때는 현재 업무 헤더로 복귀합니다.

## 자동 검사

```sh
cd integration
python3 -m unittest -v test_server.py
```

HTTP 인증·만료·거절·폴링 간격·토큰 회전/재사용 차단·취소, 계정 범위, 부분 배송·중간 인계·늦은 결과·하역과 인수 분리·냉동 이력을 검사합니다. 로컬 `*.sqlite3`는 `.gitignore`로 제외되며 계정 비밀번호나 실제 토큰을 공유하지 않습니다.

## 2.1 화면에서 확인할 것

설정 저장 전후 현재 방문지·연결·수량이 같아야 합니다. 부분 배송 후 완료한 출입구는 접히고 미처리·회수·전송 대기가 먼저 남습니다. 모든 현재 작업이 반영되면 다음 배정 대기, 하역만 끝나면 인수 미완료가 표시됩니다. 도크 호출과 온도 이상은 눈에 띄게 표시되며, 업무 종료와 오늘 운전 종료는 서로 다른 화면입니다. 큰 글자·Tab·Shift+Tab으로 펼쳐 보기와 돌아가기를 사용할 수 있습니다.
